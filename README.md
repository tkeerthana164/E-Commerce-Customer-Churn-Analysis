# E-Commerce Customer Churn Analysis

## 📌 Project Overview
This project focuses on analyzing customer churn in an e-commerce business using SQL. The objective is to understand customer behavior, identify churn patterns, and explore factors that may influence customer retention.

## 🎯 Objectives
- Clean and prepare customer data.
- Handle missing values using mean and mode imputation.
- Identify and remove outliers.
- Standardize inconsistent data values.
- Transform data by renaming columns and creating new columns.
- Analyze customer churn, payment preferences, satisfaction, and purchasing behavior.
- Combine customer and return data using SQL JOINs.

## 🛠️ Tools Used
- MySQL Workbench
  

## 📊 Key Tasks Performed
- Data cleaning and missing-value handling
- Outlier removal
- Data standardization
- Column renaming and creation
- Customer churn analysis
- Customer behavior analysis
- Aggregation using `COUNT()`, `SUM()`, `AVG()`, and `MAX()`
- Filtering and grouping using `WHERE`, `GROUP BY`, and `HAVING`
- Joining customer and return tables using `INNER JOIN`

## 🗂️ Database Tables
### 1. `customer_churn`
Contains customer information, including tenure, payment mode, satisfaction score, order count, and churn status.

### 2. `customer_returns`
Contains customer return information, including return ID, customer ID, return date, and refund amount.

## 🔍 SQL Concepts Practiced
- `SELECT` and `WHERE`
- `UPDATE` and `DELETE`
- `ALTER TABLE`
- Aggregate functions
- Subqueries
- `GROUP BY` and `ORDER BY`
- `DISTINCT` and `LIMIT`
- `IF()` function
- `INNER JOIN`

## 💡 Project Outcome
This project demonstrates the use of SQL for data cleaning, transformation, and exploratory analysis of e-commerce customer data to identify useful customer behavior and churn-related insights.
